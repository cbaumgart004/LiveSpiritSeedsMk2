Two ways into a preview of the site exist, but only one is in use. Find out whether `?edit` still
earns its place, and retire or document whichever one does not.

What the code shows (read from source on the `preview` branch, 2026-11-04):

- `?edit`: `index.html` loads the Edge of the Map console's loader, which opens the editor for a
  signed-in owner. DESIGN.md names it as the owner's editor throughout.
- `?preview` (also `?style=`, `?season=`): `src/utils/preview.js` and `components/PreviewBar.jsx`,
  a style and season toolbar that never writes to the console.
- `/preview` (a route, `App.jsx` `ToEditor`): signs the owner in through the console and returns to
  the home page with the editor open. The preview host's script in `index.html` also opens the
  editor once per tab.

**Unverified:** which of these the owner actually uses, and whether `?edit` does anything the
`/preview` route does not.
